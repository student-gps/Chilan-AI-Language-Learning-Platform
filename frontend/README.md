# Chilan frontend

This directory contains Chilan’s React + Vite learner-facing application.

## Start here

- Project overview: [../README.md](../README.md)
- Development setup: [../docs/development-guide.md](../docs/development-guide.md)
- Frontend architecture: [../docs/architecture-frontend.md](../docs/architecture-frontend.md)

## Common commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

## Environment variables

- `VITE_APP_API_BASE_URL` — backend API base URL
- `VITE_AUTH_GOOGLE_CLIENT_ID` — Google OAuth client ID for the frontend app

For repo-wide context, use the root README and `docs/` rather than the default Vite template docs.
