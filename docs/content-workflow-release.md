## 本版行为

教材提取、题库、角色语音、本地化、旁白、静态课件和媒体验收具有明确的阶段与检查点。默认运行至 `verify`，显式 `publish` 才上传并入库。上传失败、素材缺失或验证失败会中止发布。

教学图片使用独立静态组件，字幕由播放器按时间轴显示。旁白字幕和制作备注不会嵌入图片。逐页更新 Remotion 参数，避免多个教学页误用同一画面。图片和分页语音采用内容指纹文件名；交付为 WebP 与 MP3。

三套教材的后端媒体路径和静态导出器使用同一份流程清单。制课源码入库；教材 PDF、生成数据、媒体、缓存和凭据保留在本地或对象存储。
