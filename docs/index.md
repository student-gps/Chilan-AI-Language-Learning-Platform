# Chilan documentation index

This is the main public documentation entry for the Chilan repository.

If you are visiting from the README, start here for the deeper technical and project structure context behind the app, backend, and local creator workflow.

## What Chilan is

**Chilan** is an AI-powered, course-based language learning platform with structured Chinese, English, and Japanese study tracks.

Core product ideas include:

- three-tier answer evaluation: Regex → embeddings → LLM,
- FSRS-oriented review flow,
- text and speech practice,
- and local tooling for course-content production and publishing workflows.
